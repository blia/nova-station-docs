# Nova Station: операційне середовище навколо проєктів

Сьогодні я хочу вперше публічно розповісти про Nova Station.

Сучасні комп'ютери стали набагато потужнішими, але спосіб роботи з ними майже не змінився. Ми досі відкриваємо застосунки, розкладаємо вікна, перемикаємося між вкладками й самостійно тримаємо весь контекст проєкту в голові.

Код живе в редакторі. Документація - у браузері. Обговорення - у чатах. Задачі, файли, моделі, логи й повідомлення розкидані між різними програмами та пристроями.

Nova Station пропонує іншу точку відліку:

```text
not apps first
not windows first
not screens first

projects first
state first
agents first
outlets by role
```

У центрі системи знаходиться Project.

Це не просто папка, репозиторій або набір відкритих програм. Project - це цілісний робочий контекст зі станом, історією, агентами, даними, задачами, медіа, кодом, підключеними сервісами та доступними пристроями.

Один Project може продовжуватися на різних пристроях без прив'язки до однієї головної машини.

На ноутбуці він може бути повноцінним робочим простором. На телефоні - компактним інтерфейсом керування. На телевізорі - медіапредставленням. На пристрої без екрана - голосовою взаємодією через мікрофон і динамік.

Змінюється спосіб представлення, але сам Project, його стан та історія залишаються спільними.

AI-агенти в Nova Station також не є окремим чат-вікном. Вони працюють разом із системою: розуміють контекст проєкту, запускають доступні можливості, стежать за задачами й допомагають маршрутизувати результати між пристроями та інтерфейсами.

З часом багато звичних застосунків можуть перестати бути великими ізольованими оболонками. Замість цього сервіси надаватимуть дані та конкретні можливості, а Nova Station визначатиме, як їх використати й де показати результат.

Це ще дуже ранній етап. Зараз ми формуємо архітектуру Station Core Runtime - основи, яка має працювати зі станом, подіями, агентами, програмами, задачами та маршрутизацією навіть без графічного інтерфейсу.

У цьому каналі я публікуватиму головні анонси Nova Station: нові рішення, важливі зміни, результати роботи та наступні кроки.

Nova Station - project-first AI operating environment.

Be focused.
